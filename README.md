# K. — By Karim ElGhazaly / Free Portfolio Website

A static, recruiter-friendly portfolio built with HTML, CSS and vanilla JavaScript. No framework, database or paid hosting is required.

## Folder structure
- `index.html` — content, projects, experience and links
- `style.css` — visual system and responsive layout
- `script.js` — project modal, cursor and mobile navigation
- `assets/` — local portfolio images

## Before publishing
1. Open `index.html` and replace the LinkedIn placeholder with your real LinkedIn profile URL.
2. Add your preferred email or WhatsApp link in the Contact section if you want direct contact.
3. Replace/add project images inside `assets/` and update the project cards if needed.

## Publish for free with GitHub Pages
1. Create a public GitHub repository, e.g. `karim-portfolio`.
2. Upload everything inside this folder, including `assets/`.
3. GitHub → repository **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)` → Save.
6. GitHub will give you a free address like `https://YOUR-USERNAME.github.io/karim-portfolio/`.

No paid hosting is needed. You can later connect a custom domain if you decide to buy one.
